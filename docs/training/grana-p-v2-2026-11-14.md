# Grana P v2 (2026-11-14, Kaggle T4) — expanded-v2 + held-out

> Kernel: `admiragic/bh-decision-grana-p-v2` v1. LUMI cert istekao → Kaggle fallback po odluci.

## Postavka

- Baza: `mistralai/Ministral-3-3B-Base-2512`, QLoRA nf4, fp16, 3 epohe, 90/10 split.
- Podaci: expanded-v2 (2378, 8 kategorija), held-out v1 (20 neviđenih) kao test generalizacije.

## Rezultat

- `val_loss: 0.163` (238 val), `format_valid_rate: 1.0` (20/20).
- **held-out accuracy: 10/19 (53%)** — iznad šanse (~33%), daleko od trening fita.

## Dijagnoza (pošteno)

- Model na neviđenom ulazu **defaulta na o1 + risk-šablon** (`scores 0.8/0.1/0.3`, 15+ od 20 slučajeva).
  Uzrok: expanded-v2 reference su ogromnom većinom `decision: o1` — model je naučio prior labela,
  ne rasuđivanje. Memorisanje iz pilota se ovdje vidi kao class-imbalance problem.
- Gibberish proba (013): odgovoreno o1 umjesto abstain — apstinencija ne generalizira.
- Zaključak: sljedeći dataset MORA imati balansirane odluke (o1/o2/o3/abstain) i raznovrsnije
  strukture; inače svaki sljedeći run samo utvrđuje prior.

## Sljedeće

- Dataset v0.4: forsiran balans labela + više apstinencijskih i dvosmislenih primjera.
- Rerun (LUMI čim se cert osvježi, inače Kaggle) s istim held-outom kao metrom napretka.
